# 🎬 وبسایت نمایش فیلم و سریال

به اپلیکیشن فیلم و سریال خوش آمدید! این اپلیکیشن به کاربران امکان می‌دهد تا فیلم‌ها و سریال‌های مورد علاقه خود را جستجو، بررسی و کشف کنند.

## ویژگی‌ها

- **مرور فیلم‌ها و سریال‌ها**: کاربران می‌توانند به راحتی در یک کتابخانه وسیع از فیلم‌ها و سریال‌ها مرور کنند.
- **اطلاعات دقیق**: هر فیلم و سریال شامل اطلاعات دقیقی مانند امتیاز، توضیحات و تاریخ‌های انتشار است.
- **نظرات کاربران**: کاربران می‌توانند نظرات خود را ارسال کرده و نظرات سایر بینندگان را بخوانند تا به تصمیم‌گیری درباره تماشای فیلم کمک کنند.
- **محتوای مرتبط**: این اپلیکیشن عناوین مرتبط را برای بهبود تجربه تماشا پیشنهاد می‌کند.
- **عملکرد جستجو**: با استفاده از قابلیت جستجوی قوی ما، به سرعت عناوین مورد نظر خود را پیدا کنید.
- **طراحی پاسخگو**: اپلیکیشن با طراحی پاسخگو ساخته شده است تا تجربه‌ای عالی در همه دستگاه‌ها فراهم کند.

## تکنولوژی‌های مورد استفاده

- **Next.js**: فریم‌ورک React برای ساخت اپلیکیشن‌های سمت سرور و ایستا.
- **App Router**: برای مدیریت مسیرها درون اپلیکیشن.
- **Tailwind CSS**: برای طراحی و استایل‌دهی سریع و زیبا.
- **Swiper**: برای ایجاد اسلایدرها و گالری‌های جذاب.
- **Framer Motion**: برای افزودن انیمیشن‌های نرم و زیبا به اپلیکیشن.
